# AI design workflow for this repository

This is a **skill experiment**, not permission to redesign indiscriminately.

1. Read PRODUCT.md and DESIGN.md first.
2. Maintain the editorial record-sleeve metaphor, proof-led hierarchy, and one accent color.
3. Draw from Taste Skill for composition and story, Impeccable for critique/polish/hardening, Emil Kowalski for purposeful interaction and motion.
4. Real product captures over mockups. Never invent a Needle demo or represent an illustration as working product footage.
5. Keep actual contact links, semantic controls, keyboard focus, WCAG contrast, mobile layouts, and reduced motion intact.
6. Do not change corporate metrics, employment claims, or the project maturity without owner confirmation.
7. Submit focused changes for review in a PR; never deploy to production automatically.
